# Verify Outcome

1. Freeze candidate identity/revision.
2. Read acceptance and evidence requirements.
3. Execute exact checks and negative paths.
4. Bind results to environment/revision.
5. Distinguish executed, skipped, contradicted and human-required evidence.
6. Do not edit the candidate during the verification pass.
7. Return supported maturity, limitations and missing evidence.
