# Commercialization Profile

Optional overlay for projects whose originating intent includes discovery, qualification, commercialization or portfolio governance of reusable intellectual assets.

This profile adds:

```text
CALP — asset-level commercial standing
PGP  — portfolio-level disposition
```

It may also bind EQP, IEPE, ICP, PDP and SES when their actual responsibilities are required.

CALP/PGP do not alter the base meanings of work state, evidence, authority, context or agent execution.

Do not load this profile into projects that do not have a commercialization objective.
